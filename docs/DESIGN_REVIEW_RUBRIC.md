# Final Readiness Rubric

Score 0–2.

```text
0 = incorrect / cannot explain
1 = correct on familiar example
2 = correct and transfers to an unfamiliar example
```

## Categories

1. Python/control-flow tracing
2. data structures / representation choices
3. agent: goal/environment/state/action
4. LLM boundary and nondeterminism
5. tool contract / authority
6. loop state and termination
7. memory classifications
8. RAG pipeline and vector retrieval concept
9. retrieval vs generation failure
10. planning/reasoning tradeoff
11. multi-agent role/handoff/termination
12. evaluation criteria before execution
13. safety/permission boundary
14. execution trace / failure diagnosis
15. architecture explanation without framework magic

## Readiness Standard

Recommended:

- no `0` in categories 1–8;
- no more than two `0`s overall;
- score `2` on agent/tool loop, RAG pipeline, evaluation, and architecture explanation;
- any remaining weakness is explicitly written into `learning/LEARNING_LEDGER.md` as a CMU watch item.

This is a readiness test, not a claim of mastery.
